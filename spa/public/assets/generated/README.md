# Generated shared art

This directory contains only generated assets that remain in use after the
SceneV2 museum cutover:

- `favicon.ico`, `favicon-16.png`, `favicon-32.png`, and
  `apple-touch-icon.png` are application icons.
- `hero-backplate.{jpg,webp}` and `era-90s.jpg` remain source art for
  `scripts/dev/capture-poster-shots.sh`.

The v1 hall surfaces, screen states, machine textures, decade backdrops,
ultrawide wall, shelf textures, and intro mark were removed with the old
museum scene.
