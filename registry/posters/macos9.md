## Origins

By 2001 the classic Mac OS was seventeen years old and had run out of road. Apple had spent the mid-nineties failing to build its successor in-house, bought NeXT in 1996 to get one, and was now shipping two operating systems side by side: the brand-new Mac OS X, and this — Mac OS 9.2.2, released in December 2001, the final release of the system whose line began with the 128K Macintosh of 1984.

It runs here on an emulated Power Mac G4 "mac99" machine — the PowerPC generation that carried Apple through the transition years. The machine boots through Open Firmware rather than a Mac ROM, which makes this the rare classic Macintosh that an emulator can start without a dumped ROM image at all.

## Significance

Mac OS 9 is the classic system at its most capable and most contradictory. It had grown Sherlock searching, multi-user login, network file sharing, automatic software update, and a keychain — features that read as modern — and underneath them it still had **no protected memory and no command line**, still scheduled applications cooperatively, and still let one misbehaving extension take the whole machine down at boot. Every one of those limits had been a reason to build Mac OS X.

Apple named it "the best Internet operating system ever" at launch; within a year Steve Jobs was holding a stage funeral for it, coffin and all, at WWDC 2002. Both were fair. Mac OS 9 was simultaneously a dead end and the most polished expression of the interface Apple had been refining since 1984.

## What you're looking at

Mac OS 9.2.2 booted from its own disk at 1024×768 in millions of colours — the platinum appearance, the stamped-Finder-face backdrop, and the Control Strip along the bottom edge, a drawer of sliders and switches that classic Mac users either loved or immediately dragged shut. The desktop is quiet by design: one disk, a Trash, and the row of aliases a fresh 2001 install put there.

There is deliberately no network on this machine — the era's icons for Mail and Browse the Internet are present, and lead nowhere. The mouse is a USB device reporting only relative motion, with the tracking speed pinned to its slowest, most linear setting so the pointer you steer stays honest.

## Legacy

This is where the classic line ends: 9.2.2 was the last release, and the machines that shipped after 2003 could not boot it at all. It lived on for years inside Mac OS X as the Classic environment — a whole copy of this system running in a window — until Apple's Intel transition closed even that door.

What it handed forward is easy to see from here. The Finder, the menu bar, the Trash, and the one-window-one-document habit all crossed into Mac OS X intact; Sherlock's find-anything box became Spotlight; the keychain is still called the keychain. Five years and one processor architecture separate this desktop from the System 7.5.3 Quadra elsewhere in this hall — walking from one to the other is watching the same idea grow up, right to the edge of becoming something else.
