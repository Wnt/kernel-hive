## Origins

Be Inc. was founded in 1990 by Jean-Louis Gassée and Steve Sakoman, former Apple engineers, to build a new computer rather than extend an existing architecture. The result was the BeBox (1995), a dual-PowerPC machine built to showcase a new operating system, BeOS, designed around pervasive multithreading, a modern journaling filesystem, and a media pipeline for real-time audio and video. The hardware did not sell in numbers, and Be ported BeOS first to PowerPC Macintosh clones and then to x86, betting the software could succeed independent of any one machine.

BeOS Release 5, shipped in March 2000, was the last major version and the one most people actually ran. Be released it in two forms: a Professional edition sold commercially, and a Personal Edition given away free to get BeOS onto ordinary PCs, including as a second OS alongside Windows. This station runs the Professional edition.

## Significance

BeOS R5 felt immediately different from contemporaneous Windows and Mac systems. The kernel and API treated multithreading as the default, not an afterthought on older single-threaded code, so the system stayed responsive under load that stalled its contemporaries. The Be File System (BFS) made file attributes indexable and queryable, letting the Tracker file manager present live, database-like views of a directory rather than a static listing. The media kit made audio and video first-class system services, and Be's demos — dozens of video streams playing back simultaneously without dropping a frame — became a signature of the platform.

None of this translated into commercial success. Be's proposal to Apple to base the next Mac OS on BeOS was passed over for NeXT's technology in 1996/1997, widely seen as the turning point for the company. Be sued Microsoft over PC-maker bundling practices, but never built an ecosystem large enough to sustain itself, and Palm, Inc. acquired Be's assets in 2001, ending BeOS as an actively developed commercial product.

## What you're looking at

Tracker (file manager and desktop shell), Deskbar (the always-on-top menu and application switcher in the corner), and a Terminal window — the components that define a BeOS session. The yellow-tabbed windows and clean, uncluttered chrome were distinctive at the time and remain instantly recognizable.

## Legacy

BeOS's ideas outlived the company. Its interaction model and much of its API surface were reimplemented from scratch, without Be's original source, by the open-source Haiku project (started in 2001 as OpenBeOS), the actively maintained continuation of this desktop. Seeing BeOS R5 and Haiku side by side shows both the original and its free-software afterlife: one frozen where Be Inc. stopped, the other still being built.
