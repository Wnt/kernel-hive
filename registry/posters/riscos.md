## Origins

Acorn developed RISC OS for its ARM-based Archimedes computers, releasing the named system in 1989 after the earlier Arthur environment. The operating system was designed alongside the first ARM processors, whose reduced instruction set emerged from Acorn’s search for an efficient successor to the 6502 — the chip this hall also exhibits in the BBC Micro, whose own operating system was the direct ancestor of RISC OS. RISC OS placed a graphical desktop, filing system, fonts, applications, and BASIC programming environment on machines that became especially prominent in British education.

Its interface developed conventions distinct from the Macintosh and Windows. Drives and running applications occupy an icon bar along the bottom of the screen; the pinboard supplies a backdrop for files and icons; applications are packaged as directories whose names begin with an exclamation mark; and a three-button mouse assigns Select, Menu, and Adjust consistent roles.

## Significance

RISC OS is inseparable from the early history of ARM, an architecture that later spread through mobile and embedded computing worldwide. Yet the desktop is not merely a footnote to processor design. Applications such as Draw, Paint, Impression, and educational software supported a substantial culture of graphics, publishing, programming, and classroom use — by 1996, RISC OS had shipped on more than 500,000 machines.

The system’s cooperative multitasking and single-user assumptions differ sharply from contemporary protected desktop operating systems. Those limitations coexist with a responsive, compact environment whose file and font technologies were sophisticated for their time.

## What you're looking at

RISC OS 5.30 is a 2024 release from RISC OS Open, with the icon bar, pinboard, Filer, !Draw, !Paint, StrongED, and NetSurf.

## Legacy

RISC OS survives through RISC OS Open, commercial custodians, emulator users, and new ARM hardware. Its continuity connects Acorn classrooms directly to the architecture now inside billions of devices, while preserving an interface that followed its own logic. The system’s icon bar and application directories remain reminders that graphical desktops never had only one inevitable form.
