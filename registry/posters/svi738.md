## Origins

The **SVI-738 X'Press**, introduced in 1985, brought a 3½-inch floppy drive,
serial interface and 80-column text into one compact Spectravideo. Where the
SVI-728 needed an external drive for disk software, the X'Press had one beside
its keyboard. Its supplied operating systems included both MSX-DOS and CP/M.

The machine remained an **MSX1** computer, even though its V9938 video chip
also appeared in MSX2 machines. That distinction matters here: the wider text
display was useful for work without making the whole computer a new generation
of MSX.

## Significance

CP/M connected this home computer to a software tradition built around disks,
text and named files. The X'Press manual presents it as a route to business
applications, including word processing and spreadsheets. The integrated drive
and wider display made that a practical part of the machine's design.

This exhibit explores the programming side of that environment. The editor,
assembler and disk utilities share a command line; Microsoft BASIC is another
program loaded from disk. It is a different way of working from turning on an
MSX and finding BASIC already waiting in ROM.

## What you're looking at

An emulated Finland/Sweden SVI-738 with 64 KiB of RAM, running **Spectravideo
CP/M-80 2.28, X'Press release 2.1**. This is a CP/M 2.2-family system with the
International keyboard setting. The working disk includes Microsoft BASIC-80
5.21 and short examples written for the museum.

### Try it

At the `A>` prompt, type `DIR` to list files or `TYPE WELCOME.TXT` for an
introduction. `STAT CON:=UC1:` selects 80-column text;
`STAT CON:=CRT:` returns to 40 columns.

In **Controls**, choose **Type in a demo program** to load BASIC and type
an example. Allow a moment for disk loading, then press **Enter** after the
final `RUN`. In BASIC, `RUN "HELLO"` loads the example from disk;
`SAVE "VISITOR"` saves your program. Use uppercase filenames.
`SYSTEM` returns to CP/M.

**Restore to golden snapshot** resets the computer and discards your disk changes.

## Legacy

The X'Press shows how much an operating system could change the use of a home
computer. Its MSX hardware supported both the familiar BASIC environment and
the disk-based tools seen here. Alongside the earlier Spectravideo stations,
it records the move from adding peripherals to building a more complete
working system into the case.
