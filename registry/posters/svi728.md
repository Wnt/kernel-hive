## Origins

The SVI-728 brought Spectravideo into the MSX standard. Its familiar keyboard
computer form held BASIC in ROM, color graphics and programmable sound.
A shared software standard connected it to machines from other manufacturers.

## Try it

At `Ok`, type `PRINT 1+1` and press Enter. The Type demo button enters a short
program with a greeting, a table of squares and a musical scale. Press Enter
after the final `RUN` to start it. Change a numbered line and run it again.

Reset returns to an empty BASIC prompt. This exhibit uses the International
keyboard model, with no disk expansion attached.
