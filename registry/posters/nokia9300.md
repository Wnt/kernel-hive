## Origins

Nokia sold its first **Communicator**, the 9000, in 1996: a phone that opened like a book to show a wide screen above a full keyboard. In 2001 the **Nokia 9210** brought the idea to Symbian OS, with the interface called **Series 80**. It was built for a 640 by 200 landscape screen and a full keyboard, not a phone keypad.

The second generation came in 2004. Nokia introduced the **9500 Communicator** in February and shipped it in November. On **8 September 2004** it announced the **Nokia 9300**, with sales planned for the first quarter of 2005. The 9300 was the smaller, cheaper version of the same machine. It was 55 grams lighter than the 9500 and left out the camera and wireless LAN, but it kept the same 150 MHz Texas Instruments OMAP processor, the same memory and the same 640 by 200 inner screen in 65,536 colours. Nokia did not market it under the Communicator name. Its own user guide calls it the Nokia 9300 smartphone.

Both run **Series 80 v2** on **Symbian OS 7.0s**. Closed, the 9300 is an ordinary phone with a keypad and a small outer screen. Open, it is the machine in front of you. A full keyboard sits below the wide screen, with a row of application keys along the top of it: Desk, Telephone, Messaging, Web, Contacts, Documents, Calendar and a My own key you can assign. **Four command buttons** stand to the right of the screen. The software writes their current meaning beside them: Open, Write note, Exit. A joystick and four arrow keys move the selection, and a Menu key opens each application's menu bar. There is no stylus and no touchscreen. Series 80 was designed from the start to be driven from the keys.

In 2005 Nokia added Wi-Fi to the smaller body as the **Nokia 9300i**, which shipped in 2006. It was the last Series 80 device.

## Significance

The 9300 is the pocket office of its time, and its applications show what that meant: **Documents**, **Sheet** and **Presentations** for Word, Excel and PowerPoint files; **Messaging** for text, multimedia messages and e-mail with attachments; a calendar and contacts; and **Web**, a Nokia-branded **Opera** browser that renders full HTML pages as well as WAP pages. The build in this firmware reports itself as Opera 6.0.

What made this work on a phone was the screen, not the processor. At 640 pixels, a line of a document or a row of a spreadsheet fits across the display at a readable size. Series 80 uses that width the same way in every application: the content on the left and the command buttons' labels on the right, so the layout you learn on Desk holds everywhere else.

Underneath is Symbian OS 7.0s: a multitasking operating system with its own window server, font and bitmap server and application framework, in a device that fits in a pocket.

## What you're looking at

This is the 9300's own firmware, **version 5.22**, dated 16 November 2005, running unmodified in an emulator. The emulator is **EKA2L1**, an open-source Symbian emulator. Upstream, it recreates Symbian's kernel and system servers in its own C++, mainly for phone games. The museum's fork extends it for Series 80 and goes further: here the firmware's **own window server, font and bitmap server and Eikon application framework** run from the device's ROM. Every pixel on the screen is drawn by the code Nokia shipped, at the 9300's 640 by 200 resolution, shown at twice its size. The clock and date follow the museum's time zone, Helsinki.

This exhibit is **keyboard only**, as the device was. There is no pointer, and clicking on the picture does nothing. The page shows the 9300 drawn open with the legends of its Nordic keyboard. You can press the drawn keys or use your own keyboard. On your keyboard, F1 to F4 are the four command buttons, F5 to F12 are the application keys from Desk to My own, and Escape cancels a selection or closes a dialog. Type into Documents, fill in a Sheet, or move around Desk with the arrow keys.

**Web** is connected, but not to today's internet. It reaches the museum's archived-web network, a private collection of period web pages. Press F8, then the first command button, Open Web address, and give it an address. The browser and the firmware's own HTTP code build each request, and the emulator carries it to the archive. There is no SIM card, so Telephone has no network to call.

**Reset** returns the machine to the Desk shown here. Whatever you typed is discarded, so the documents you write belong to your visit.

## Legacy

Series 80 ended with the 9300i. The last Communicator, the **E90** of 2007, kept the fold-open design but ran **S60 3rd Edition**, the platform of Nokia's keypad smartphones. There was no Series 80 v3.

The 9300 had one turn in the cinema: it is the hacker Matt Farrell's phone in *Live Free or Die Hard* (2007). Symbian's source code was later published under an open-source licence, and people still write software for these machines and test browsers against them. EKA2L1 is part of that work. This exhibit adds the 9300's own window server, drawing its own screen again.
