## Origins

The **Spectravideo SV-328**, introduced in 1983, put a Z80 processor, 64 KiB of main memory and Microsoft's SV Extended BASIC inside a keyboard computer. Another 16 KiB served the colour display. BASIC was stored in ROM: switching on brought the owner straight to a language for writing programs, with no disk to load first.

Spectravideo's manual treated programming as part of learning to use the machine. It led readers from their first numbered lines through loops, graphics and sound. The computer could also grow through an expansion unit, with cards for disks, additional memory and an 80-column display. The gallery's separate CP/M exhibit shows that expanded form.

## Significance

The SV-328 belongs just before Spectravideo's move to MSX. Its Z80, colour graphics, programmable sound and Microsoft BASIC make it look familiar beside an MSX computer, but it is a **pre-MSX machine with its own software environment**. The later SVI-728 in this gallery is the MSX model.

The BASIC prompt also explains a different relationship between owner and computer. A command without a line number runs immediately; a numbered line becomes part of a stored program. The same screen is a calculator, an editor and the place where the result appears. The owner's manual makes that progression explicit, including graphics and sound in the language the beginner is already learning.

## What you're looking at

This is the PAL SV-328 at its blue power-on screen: **SV extended BASIC version 1.1**, Microsoft's 1983 copyright and `Ok`. It has the standard 64 KiB of main memory, with no disk drive, cartridge or expansion card attached. The function-key labels along the bottom belong to BASIC itself.

### Try it

At `Ok`, type `PRINT 328` and press Enter. For a longer example, open **Controls** and choose **Type in a demo program**. It replaces any program in memory with a short listing. Wait until the final `RUN` appears, then press Enter to print the machine's name and the squares of 1 through 5.

Type `LIST` to read the program. Enter `30 FOR I=1 TO 10`, then `RUN`, to extend the table. **Ctrl+End** sends Ctrl+STOP and interrupts a running program. The exhibit translates the SV keyboard's colon and semicolon positions for typing.

**Restore to golden snapshot** resets the machine to the empty BASIC prompt and discards your program. This exhibit runs offline.

## Legacy

The SV-328 and SVI-728 preserve two consecutive stages in Spectravideo's history: a manufacturer's own home computer, followed by a machine built to a shared standard. Here, before that change, the distinctive experience is immediate access to the programming language. The empty prompt is an invitation to make the next thing that appears on the screen.
