## Origins

Switch on a Spectravideo SV-328 and BASIC is ready. The screen belongs to the program you write.

Open Controls and choose **Type in a demo program** to enter numbered BASIC lines. Press Enter after the final RUN to print a table of squares. Change the loop limit, then type `RUN` again. `LIST` shows your program.

Try `PRINT 328` at `Ok`. Use Ctrl+End (the SV STOP key) to interrupt a running program. The built-in function-key labels offer another way to explore.

Reset returns to a clean BASIC prompt. This exhibit runs offline.
