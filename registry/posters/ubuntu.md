## Origins

**Ubuntu 4.10**, code-named Warty Warthog, was released on **20 October 2004** by
**Canonical**, the company Mark Shuttleworth founded to build it. The team took
a snapshot of Debian's unstable branch (`sid`), chose one desktop — **GNOME 2.8**
— and one set of default applications, and committed to a new release every
**six months**, timed to follow each GNOME release. The version number is the year
and month: 4.10 is October 2004.

The slogan was "Linux for human beings", and the distribution was aimed at the
desktop rather than the server. Canonical's **ShipIt** programme posted pressed
CDs anywhere in the world free of charge, which is how many people first met it:
one install CD, one live CD, in a cardboard sleeve.

## Significance

Warty mattered less for any single feature than for the package as a whole. Debian
supplied the base and the package tools; Ubuntu supplied the decisions Debian
declined to make — one desktop, one browser, one office suite, a single CD, and a
fixed calendar. The desktop was GNOME 2.8 in Canonical's own brown **Human**
theme, with **Firefox 0.9**, **Evolution 2.0**, **OpenOffice.org 1.1** and
**GIMP 2.0** preinstalled.

Two policy choices from this release stuck. There is no root password: the first
user administers the machine through **`sudo`**. And the release came with a
support promise — **18 months** of security updates — at a time when most
community distributions promised nothing at all. The live CD, built on the same
Casper technology as the installer, let a visitor try the desktop without touching
the hard disk.

## What you're looking at

A 2004-class PC with 512 MB of RAM and a standard VGA card, booting the official
Warty **live CD**. There is no hard disk installation: the CD is the operating
system, and the session runs in memory as the user **`ubuntu`**.

The top panel holds the **Applications** and **Computer** menus — GNOME 2.8 put
places and preferences under Computer, a layout GNOME 2.10 split into the later
Applications/Places/System trio. The **cdrom** and **ramdisk** icons on the desktop
are the two volumes the live session mounted. The bottom panel is the window list.
Press **Alt+F2** for the Run Application dialog; **Escape** closes it.

Nothing you do is written to a disk. Every reset restores the same instant of the
same live session, exactly as it appears here.
