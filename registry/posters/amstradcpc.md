## Origins

Amstrad introduced the CPC 6128 in 1985 as the most capable member of its original Colour Personal Computer range. The British company had entered home computing only the previous year with the CPC 464, offering a practical package that included the computer, keyboard, cassette recorder, and dedicated monitor. The design brief behind the range, stated by founder Alan Sugar, was that a home computer should arrive complete — its own monitor, a full-size keyboard, a built-in tape mechanism — so the family’s television could stay free. The 6128 retained the integrated keyboard computer but added 128 KB of RAM and a built-in 3-inch floppy-disk drive, giving families, schools, and small businesses a more serious machine without abandoning the range’s approachable design.

At its heart is a Zilog Z80A processor running at 4 MHz. Because the processor directly addresses 64 KB, the additional memory is selected in banks for software that knows how to use it. Amstrad supplied the machine with a colour or green-screen monitor, which also powered the computer. Locomotive BASIC 1.1 and the AMSDOS disk system reside in ROM, so the machine starts at a programming prompt without requiring a disk.

## Significance

The CPC 6128 occupies a distinctive place in the crowded European 8-bit market. It competed with the Sinclair ZX Spectrum, Commodore 64, and BBC Micro through integration rather than a single headline specification. Buyers received a matched computer, monitor, keyboard, and disk drive, avoiding the uncertain mixture of televisions, recorders, and peripherals common to home computing.

Its 27-colour palette, selectable screen modes, AY-3-8912 sound chip, and capable BASIC supported games, artwork, education, and programming. The disk drive made loading and saving faster than cassette and opened access to substantial applications such as Protext and The Advanced OCP Art Studio. CP/M Plus extended the machine toward established business software, while AMSDOS made disk commands available from BASIC.

## What you're looking at

The opening screen identifies an “Amstrad 128K Microcomputer” and Locomotive BASIC 1.1 before presenting the yellow-on-blue *Ready* prompt. A flashing block marks the point where typing begins. There is no graphical desktop to navigate: this is a keyboard machine, and the command line is both its immediate workspace and the entrance to stored programs. BASIC statements can be entered for instant execution or assembled into numbered lines, saved to disk, and run as a program.

## Legacy

The machine it spent the mid-1980s outfighting sits next door in this museum: the Sinclair ZX Spectrum, the cheaper rubber-keyboard rival whose bare grid of keys had no dedicated function keys — the CPC’s most advertised answer to it. The CPC range became a major part of home computing in Britain, France, Spain, and other European markets, sustaining a large library of commercial games and practical software. The 6128’s extra memory and disk drive made it the enduring high-end model of the classic line. Its direct invitation to type remains the essential artifact of the period: switching on the computer does not merely launch software, but places the user inside a programming language.
