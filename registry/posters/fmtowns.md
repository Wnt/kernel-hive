## Origins

Fujitsu built the FM TOWNS around a bet almost nobody else was making in 1989: that a CD-ROM drive belonged in a personal computer as standard equipment, not as an add-on for the rare buyer who owned one. Every FM TOWNS shipped with a double-speed CD-ROM drive, a 32,768-colour palette, dedicated sprite hardware and a PCM/FM sound chipset built for game and multimedia software rather than spreadsheets — running on an Intel 386, later 486, at a time when most Japanese desktops were still built around NEC's PC-98 line and its 8-bit-descended graphics. It was a strange, specific machine: IBM-PC-adjacent enough to run MS-DOS underneath, but with a video and audio subsystem closer to a game console's.

Towns OS is Fujitsu's answer to what a CD-native operating environment should look like. It boots from the disc itself — there is no installer step, no hard disk required — straight into TownsMENU, an icon desktop laid over an MS-DOS kernel that quietly handles the files underneath. Double-click a folder, and TownsMENU opens a window onto it; the whole environment exists to get a CD's worth of software running with as little typing as possible, which is exactly what a machine sold to play CD-ROM games and multimedia titles needed.

## What you're looking at

This station boots the Towns System Software V2.1 L51 CD cold, with no software installed on top of it — the exhibit is the environment itself: TownsMENU's drive-select window, the CD's own utility folder, and the desktop a 1995 owner would have seen before ever reaching for a game disc. The FM TOWNS built a large, mostly Japan-only software library on the strength of that CD drive — RPGs, adventure games, and ports that used its colour depth and audio to outdo their PC-98 and Spectrum-generation counterparts — none of which lived on this particular disc, but all of which depended on the platform this desktop represents.
