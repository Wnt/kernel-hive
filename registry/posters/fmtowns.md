## Origins

In February 1989 Fujitsu shipped the **FM TOWNS**, and put a CD-ROM drive in it as standard equipment. That one decision is why the machine is remembered. In 1989 a CD-ROM drive was an expensive add-on card-and-caddy affair for a PC, if you could get one at all; Fujitsu made it the boot device, the software distribution medium and the music player of a consumer personal computer, years before the rest of the industry agreed that was the obvious thing to do.

The hardware around it was aimed squarely at what a disc full of data could be used for. A 386 at the start of the line, 486s and eventually Pentiums later; sprite hardware of the kind you would expect in a games console rather than an office PC; video modes reaching into the 16.7-million-colour range; and a sound section that paired FM synthesis with 16-bit PCM channels — and, of course, the CD itself, so a game could simply play a Red Book audio track as its soundtrack. The FM TOWNS was a Japanese personal computer that had quietly been designed as a multimedia machine before the word had settled into marketing.

Fujitsu built it a software world to match. The system that shipped on the disc was **Towns OS** — not a kernel of its own, but Fujitsu's graphical shell running on MS-DOS, with the **TownsMENU** launcher as the face a visitor actually meets. The Towns System Software line ran from **V1.1 in 1989** through to **V2.1**, whose **L51** release of **1995** is the one this exhibit runs. Underneath the icons it stayed DOS all the way: the CD games and multimedia titles that made the platform's name were DOS-extender programs that Towns OS launched and got out of the way of. The library is the argument for the machine — arcade conversions like *Afterburner*, the Towns editions of the *Ultima* series, the "Free Software Collection" discs that packed shareware, tools and demos onto CDs in an era when a single disc held more than most people's hard drives.

In 1993 Fujitsu took the same architecture, dropped the keyboard and sold it as a games console: the **FM Towns Marty**, a 32-bit CD console that arrived before anyone else had one, and sank anyway.

## Significance

The FM TOWNS is the clearest case in the museum of a company being right early and getting no credit for it. Everything the mid-1990s multimedia PC was sold on — boot and install from CD, full-colour graphics, sampled audio, games with recorded soundtracks — the FM TOWNS shipped as the default configuration in 1989. What it did not have was the rest of the world. It was a Japanese machine for the Japanese market, competing at home against NEC's entrenched PC-98 line and abroad against nothing, because it was never seriously sold abroad. When PC/AT compatibles with Windows swept the Japanese market in the mid-1990s, a platform whose whole software library was its own had nowhere to go, and Fujitsu wound the line down.

Towns OS itself is worth looking at for a reason that has nothing to do with CDs. It is a DOS graphical shell — the same problem PC/GEOS, Windows 3, and the DESKTOP of a dozen other products were solving on the other side of the Pacific — solved with a different set of assumptions: a fixed, icon-first launcher rather than a window manager, because the thing you were about to do was almost certainly on a disc you had just inserted.

## What you're looking at

Towns OS V2.1 L51, the 1995 release, running on FM TOWNS hardware. **The desktop is in Japanese** — the menus, the icon labels and the system dialogs are all in kanji and kana, as every FM TOWNS shipped. You do not need to read them to see what is happening; the layout is spatial and the icons are pictures, which was rather the point of TownsMENU in the first place.

The station comes up on **TownsMENU** with a ドライブ選択 (drive-select) window open over the desktop and the CD's own Q:TOWNSSYSTEM folder already showing its contents — TownsGEAR, TownsStaff and FM-OASYS among the icons on the boot disc. Nothing is installed on top of it; this is the System Software CD's own utility folder, exactly as a 1995 owner would have found it straight off the boot disc.

The pointer is not wired up on this exhibit yet — the FM TOWNS mouse talks to the machine over a path the museum's tooling has not proven a route through — so the way in for now is the keyboard. **Ctrl+Esc** opens the guest's own タスクリスト (Task List) dialog; press it again and a different one appears, サイドワークリスト, Towns OS's own list of accessories (Control Panel, calculator, CD player, schedule). Each keypress reaches the guest live — the second dialog is not the first one redrawn, it is the shell answering a different question.

## Legacy

The FM TOWNS is the museum's second Japanese desktop, and it stands beside `chokanji` — Ken Sakamura's BTRON, the operating system Japan designed and then set aside — as the other half of the same story. Both were built in Japan, for Japan, with ideas the rest of the industry arrived at later; both lost to the PC/AT and Windows; and both are worth looking at precisely because they are not what won. Chokanji shows a desktop built on a wholly different idea of what a file is. FM TOWNS shows a machine that guessed, correctly and five years early, what a personal computer was going to be for — and then watched someone else's hardware get there.
