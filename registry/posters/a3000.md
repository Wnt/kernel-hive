## Origins

The Amiga 3000, released in June 1990, was Commodore's attempt at a machine an engineering department would take seriously. Where the Amiga 500 had been a wedge-shaped home computer, the 3000 came in a low desktop case with a monitor sitting on top, and it carried the parts the earlier Amigas had gone without: a Motorola 68030 processor with its memory management unit fitted rather than omitted, a 68882 floating-point unit beside it, four 32-bit Zorro III expansion slots, a SCSI controller doing direct memory access on the motherboard, and a display enhancer that de-interlaced the Amiga's flickering high-resolution screens onto an ordinary VGA monitor. The custom chips — Agnus for memory access and the blitter, Denise for graphics, Paula for sound and disk — were the Enhanced Chip Set, ECS, the last revision before the AGA machines of 1992.

The software was new too. The Amiga 3000 was the first machine to ship with **Kickstart 2.0** and Workbench 2.0, the largest rewrite AmigaOS ever received. Version 1.3's blue-and-orange desktop was replaced by the grey, three-dimensional look on this screen; the Shell became a usable command line with history and editing; a standard **Installer** and the **Commodities Exchange** for background utilities arrived; and the operating system finally gained the layout conventions — the Amiga User Interface Style Guide — that made third-party applications resemble each other. Kickstart 2.04, revision 37.175, is the settled version of that release, and the one this machine boots.

## Significance

Workbench 2.0 is where the Amiga stopped looking like a games machine with a menu bar. Almost everything a later Amiga user recognises begins here: the grey palette, the sizing gadgets, the ASL file requester, the public-screen mechanism that let applications open on each other's screens, ARexx shipped as part of the system rather than as an add-on. AmigaOS 3.1, still being maintained for 68k hardware in the 2020s, is a refinement of this design rather than a departure from it.

The hardware mattered for a reason that is easy to miss on a desktop screenshot. The memory management unit is what separates a machine that can run one program carefully from one that can run many programs safely — and it is why Commodore could sell the same box, as the **Amiga 3000UX**, with a licensed AT&T System V Release 4 Unix on it. That configuration is another exhibit in this gallery: the `amix` station is an Amiga 3000, the same processor and the same Kickstart 2.04 ROM as this one, booting Amiga UNIX instead of Workbench. Two operating systems, one machine, and the clearest illustration in the hall of what an Amiga was actually capable of.

## What you're looking at

An emulated **Amiga 3000** — 68030 at 16 MHz with a 68882 floating-point unit, the ECS chipset, 2 MB of chip RAM and 8 MB of fast RAM, Kickstart 2.04 revision 37.175 from the A3000 ROM — booting **Workbench 2.04, revision 37.67**, from a hard disk composed on the host from Commodore's four original Workbench floppies.

The desktop is deliberately bare, because that is what a freshly installed 2.04 system looks like: the Workbench window with the system volume and the RAM disk, the copyright line along the title bar, and the red Amiga arrow for a pointer. Double-click the disk to open it and the drawers are the standard ones — Utilities, Tools, Prefs, System, Expansion. The Prefs drawer is where Workbench 2.0's new preferences editors live, one per setting rather than the single panel of 1.3, and the Shell in System is AmigaDOS 2.0's, the one that finally remembers what you typed.

This machine has no network. In 1990 an Amiga on a desk was not on the internet, and the exhibit does not pretend otherwise — there is no browser here and nothing to dial.

## Legacy

The Amiga 3000 sold in modest numbers against workstations from companies with longer reputations, and Commodore's collapse in 1994 ended the line four years after this machine shipped. What survived is the software design. Workbench 2.0's interface carried through 3.0, 3.1 and the community releases that followed it, and the AmigaOS lineage continues today in OS 4 on PowerPC, in the AROS reimplementation elsewhere in this gallery, and in Hyperion's 68k releases for hardware like this one. The 3000 itself is remembered as the best-built Amiga Commodore made: the one machine in the family where the engineering ambition and the case it came in agreed with each other.
