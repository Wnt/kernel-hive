## Origins

In December 1996 Apple bought NeXT, and with it NeXTSTEP/OPENSTEP — a Mach kernel with a BSD personality, Display PostScript, and the Objective-C application frameworks — to become the foundation of its next operating system. The plan, code-named Rhapsody, was to put the Macintosh look on top of that NeXT system: the Platinum appearance of Mac OS 8, a Mac-style menu bar and Finder, over the NeXT Workspace, NetInfo, and a Unix shell. Developer Release 1 shipped in the autumn of 1997; **Developer Release 2 (Rhapsody 5.1, May 1998)** — this station — was the last release seeded to developers before Apple renamed the shipping product Mac OS X Server 1.0 in 1999.

Like NeXTSTEP before it, Rhapsody was built for more than one processor. This is the **Intel** build, running on an ordinary PC of the period — the same 1998 hardware the NeXTSTEP 3.3 exhibit's Intel port would have run on — rather than a PowerPC Macintosh. Apple dropped the Intel version from the public roadmap after DR2; the next time it surfaced was inside Apple, as the secret Intel builds of Mac OS X that came out in 2005.

## Significance

Rhapsody is the hinge between two systems shown elsewhere in this hall. Next to the NeXTSTEP station you can see what Apple kept — the Workspace, the Dock-like shelf, the installer, `bash` and Display PostScript underneath — and next to the Mac OS poster you can see what it added: the Platinum window chrome, the Apple menu, the Mac Finder. The "Yellow Box" (the NeXT frameworks, later Cocoa) and the "Blue Box" (a whole classic Mac OS running in a window for old applications) were the two halves of Apple's transition story, and Rhapsody DR2 is where both first appear together.

## What you're looking at

Right now: the installation itself, running live. Once installed, the Platinum Finder desktop over the NeXT Workspace at 800×600 — Mac OS 8 looks, NeXT bones.

## Legacy

Rhapsody became Mac OS X Server 1.0 (1999), then — with a new Aqua interface, Carbon for classic Mac applications, and the Cocoa name for the NeXT frameworks — Mac OS X 10.0 in 2001. Everything Apple ships today, from macOS to iOS, descends from the system on this screen.
