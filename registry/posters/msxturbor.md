## Origins

The MSX standard joined hardware from several manufacturers around compatible
software and peripherals. Panasonic's FS-A1GT took that family into the early
1990s with an R800 processor alongside the familiar Z80, 512 KiB of RAM and
built-in MSX-DOS 2 and MSX View software.

## What you're looking at

This is the machine's original Japanese graphical environment. Its mouse-driven
shell connects a disk browser, drawing and writing tools. The period interface
is preserved. The system disks and built-in firmware belong to this particular
Panasonic machine; it is not a later Spectravideo model.

## Try it

Open the top menu 道具 (Tools), then choose DRAW, PAINT, or TED (the text
editor). The original interface is Japanese; application names in that menu
are written in Latin letters. Double-click a disk or folder icon to browse.
The 内蔵ソフト icon opens Panasonic’s separate built-in software menu.
In DRAW, click a tool, click the first corner, move, then click again to
finish the object. The text tool (文) creates a box the same way; then type.

Reset returns the station to fresh disks and machine settings. This exhibit
is offline.
