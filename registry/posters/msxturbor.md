## Origins

The MSX standard joined hardware from several manufacturers around compatible
software and peripherals. Panasonic's FS-A1GT took that family into the early
1990s with an R800 processor alongside the familiar Z80, 512 KiB of RAM and
built-in MSX-DOS 2 and MSX View software. Its Japanese desktop offered a way
to find files and open applications with a mouse.

## Significance

The FS-A1GT shows how far the MSX family had developed beyond its early
BASIC-and-cartridge machines. Panasonic combined a faster processor and more
memory with drawing, painting and text tools. A home computer could now offer
several routes into its software: the BASIC prompt, a disk command line and
a graphical desktop.

MSX View makes that change visible. Menus and icons organize work that an
earlier MSX user would have approached through typed commands. The Japanese
labels and text-entry system also place this particular machine in the market
for which Panasonic designed it.

## What you're looking at

An emulated **Panasonic FS-A1GT**, running its original Japanese MSX View
environment with the matching system disk. The opening screen is VSHELL,
the shell from which you browse disks and launch tools. ViewDRAW 1.1 is the
drawing application shown in the second image.

### Try it

Open the top menu 道具 (Tools), then choose DRAW, PAINT, or TED (the text
editor). The original interface is Japanese; application names in that menu
are written in Latin letters. Double-click a disk or folder icon to browse.
The 内蔵ソフト icon opens Panasonic’s separate built-in software menu.
In DRAW, click a tool, click the first corner, move, then click again to
finish the object. The text tool (文) creates a box the same way; then type.
The original Japanese input mode may show kana; press Enter to commit the text.
To save, open DRAW’s top-left menu and choose **保存** (Save), select drive A,
wait for the directory listing, enter a filename in the bottom field, then
click **保存**.

**Restore to golden snapshot** returns the computer to its original disks and
settings, discarding your changes. This exhibit is offline.

## Legacy

The turbo R belongs to the later Panasonic branch of MSX history. It extends
the family represented by the museum's Spectravideo and Philips machines,
while giving it a distinctly early-1990s desktop. Compare it with the SymbOS
station: MSX View shows software supplied for a contemporary computer, while
SymbOS shows what enthusiasts later built for older MSX hardware.
