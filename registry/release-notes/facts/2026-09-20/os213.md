# os213 — facts for release notes

**What arrived:** IBM OS/2 1.30.2 Standard Edition with Presentation
Manager — the Desktop Manager shell, installed from IBM's own 10-floppy SE
set onto a FAT disk under the fleet's QEMU on an ISA i486 (`-machine isapc`,
no PCI bus at all). This is the last operating system IBM and Microsoft
built together before Windows 3.0 ended the partnership.

**Year:** 1990 (OS/2 1.3; Presentation Manager itself first shipped with
OS/2 1.1 in 1988).

**What a visitor can do:** drive the PM Desktop Manager and OS/2 Command
Prompt with keyboard and a PS/2 relative mouse — there is no absolute
pointer route on this machine, since `isapc` has no USB bus at all.

**What was hard, in order of cost:**
1. The obvious media — a preinstalled Microsoft OS/2 1.30.1 Server disk
   image — booted to a genuine banner and then wedged at a truncated `TRA`
   panic every time, no matter what was changed about the device set (RAM,
   CPU, machine type, even a probe for the well-known OS/2 "CPU too fast"
   timing bug). Four theories were raced in parallel rather than bisected
   one at a time; all four either reproduced the identical wedge or made
   things worse. The image itself turned out to be unbootable for this
   fleet, not the emulator — the station installs fresh from IBM's own SE
   floppy set instead, which just works.
2. Disk geometry: pinning the exact cylinder/head/sector geometry from the
   source image's descriptor is tempting, and wrong twice over — QEMU 11
   rejects it outright on the drive line, and even placed correctly it made
   the boot worse than simply letting QEMU auto-detect.
3. OS/2 1.3 predates PCI outright, so a modern default QEMU machine type
   freezes the guest before it ever gets to run OS/2 code — the fix is
   `-machine isapc`, the same route `nt351` (Windows NT 3.51) already uses.
