## New stations

<u>[Genode Sculpt OS](station:sculpt) joins as the museum's first microkernel desktop.</u> Genode Labs' Sculpt 25.04 turns the operating system itself into the interface: the **Leitzentrale** draws the running machine as a live graph of components, and every driver, service and application is a node the visitor can add, wire and inspect while it runs. The exhibit rests with the network up on the retronet and the **+** menu open on its Options, so toggling audio, a touchpad or the system clock grows the graph on screen. It runs under KVM with a relative USB mouse: Genode's HID driver never binds QEMU's absolute tablet, so the pointer is the museum's exact one-pixel-per-unit relative bridge, measured on the framebuffer.
