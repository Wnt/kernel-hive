# Image credits — exhibit poster galleries

The Kernel Hive source code is MIT-licensed (see [`LICENSE`](../LICENSE)). The
historical photographs bundled under `spa/public/posters/*/gallery/` are **not**
ours: each is third-party work reused under the free license listed below, and
each remains the property of its author.

Every image here was sourced from Wikimedia Commons and its license was verified
mechanically against the Commons API by `scripts/tools/fetch-poster-gallery.py`,
which refuses any license outside a fixed free-license allowlist. Re-check the
shipped set at any time with `make poster-gallery-verify`.

**204 images across 46 exhibits.** 102 of them are share-alike
(CC BY-SA): if you redistribute a modified version of one of those images, you
must license the modification under the same terms. The images are not combined
with the source code and do not affect the MIT license of the code itself.

Period advertisements and sales posters are essentially never freely licensed.
None are redistributed here; where one is relevant it is referenced as an
outbound link only (2 such link(s) below).
