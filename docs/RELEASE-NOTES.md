## Week 4 · The doors open to everyone · 2026-08-23 09:00 – 2026-08-30 09:00

### New stations

Three machines joined the floor, and one of them needed its graphics card built from scratch first. [AIX](https://kernelhive.madekivi.fi/os/aix432) is IBM's own Unix on IBM's own *PowerPC* workstation, and it refused to paint a desktop until the museum wrote that workstation's *Matrox* card into the emulator itself. The reward is a full **CDE** desktop, **Netscape Communicator**, and **Quake** running its demo loop on a *1999* RS/6000. [Mac OS 9](https://kernelhive.madekivi.fi/os/macos9) is the last classic Mac OS — one menu bar, no protected memory, the Finder as the whole machine — and the first *PowerPC* Macintosh here. [超漢字](https://kernelhive.madekivi.fi/os/chokanji) is the strangest arrival yet: Ken Sakamura's **BTRON** desktop, where every file is a 'real object', heir to the system Japan once planned for all its schools. That makes 72 machines, 68 of them open to visitors.

### Major features

<u>You no longer need an invitation to use the museum.</u> Anyone can sign up and be handed a machine of their own — [Windows 3.11](https://kernelhive.madekivi.fi/os/win311), [OS/2 Warp](https://kernelhive.madekivi.fi/os/os2warp) or [Rhapsody](https://kernelhive.madekivi.fi/os/rhapsody) — a private copy that is yours for the visit. Install something, break something, close the tab: the next visitor still gets a pristine one. The museum's private 1990s internet grew as well. Five more machines signed on to **ICQ**, taking the chat network to eleven: [Windows XP](https://kernelhive.madekivi.fi/os/winxp), [Windows 95](https://kernelhive.madekivi.fi/os/win95), OS/2 Warp on a client from before the protocol changed, [Windows 2000 on *Alpha*](https://kernelhive.madekivi.fi/os/w2kalpha) — running the ordinary *x86* client through the Alpha's own translator — and an [SGI Indy](https://kernelhive.madekivi.fi/os/irix), whose sign-in kept crashing the emulator until the fault was traced into its instruction translator and fixed. More machines browse the archived 1998 web too, each with the browser it would really have had: **Mosaic** on [HP-UX](https://kernelhive.madekivi.fi/os/hpuxvue), **WebExplorer** on OS/2, **OmniWeb** on Rhapsody.

### Quality improvements

[Mac OS 9](https://kernelhive.madekivi.fi/os/macos9) used to wake up confused, because the emulator had never saved the machine's own clock; it now comes back exactly where you left it. [NeXTSTEP](https://kernelhive.madekivi.fi/os/nextstep) moved to a colour *NeXTstation*, and its double click works from a phone at last. [Windows 95](https://kernelhive.madekivi.fi/os/win95) drops off the chat network when it sits idle, and now dials back in by itself, with nothing to prod. The two *Alpha* machines share one build of their emulator, with a fix for mouse moves it had been quietly throwing away. And the museum keeps a written account of each week now, on its own About page — which is where you are reading this.

### Also this week

- [AIX](https://kernelhive.madekivi.fi/os/aix432) brings **CDE**, the desktop nearly every Unix vendor settled on, running on the line that carried IBM's Unix into the POWER era
- [超漢字](https://kernelhive.madekivi.fi/os/chokanji) files its documents in a 原紙箱, a 'master-paper box', around a kanji set built for scholarship rather than office work
- Period sites now arrive as their most complete snapshot rather than their closest-dated one, so a 1997 page shows up with its pictures instead of grey boxes
- [Windows 3.11](https://kernelhive.madekivi.fi/os/win311) reaches the archive in **Netscape 4.08** — a *1993* desktop on a 1998 web
- [Windows XP](https://kernelhive.madekivi.fi/os/winxp) reads the same pages in **Internet Explorer 8**, five years of browser history apart
- **Mosaic** could not read the archive's own search page until it was rebuilt in markup from Mosaic's own decade
- [Mac OS 7.5.3](https://kernelhive.madekivi.fi/os/macos753) joined the period web this week, on emulated *68040* hardware
- [Rhapsody](https://kernelhive.madekivi.fi/os/rhapsody) got **OmniWeb 3.0**, the NeXT-lineage browser, sitting on the desktop where you can find it
- [OS/2 Warp](https://kernelhive.madekivi.fi/os/os2warp) chats through **ICQ/2 1.503i**, the OS/2 native build, speaking an older protocol nobody else here uses
- The gallery installs onto a phone's home screen like an app, and its collection page pulls to refresh
- The [SGI Indy](https://kernelhive.madekivi.fi/os/irix)'s browser stopped nagging on every launch: the setting that silences it is not the one you would guess

## Week 3 · The museum gets its own internet · 2026-08-16 09:00 – 2026-08-23 09:00

### New stations

Seven machines joined the floor, each installed from original media the museum tracked down itself. [NEWS-OS](https://kernelhive.madekivi.fi/os/newsos) is Sony's own Unix, running on a *1991* *MIPS* laptop. [A/UX](https://kernelhive.madekivi.fi/os/aux) is Apple's strangest hybrid: a Unix root prompt living inside the Macintosh Finder. [SunOS](https://kernelhive.madekivi.fi/os/sunos414) brings up **OPEN LOOK** and [HP-UX](https://kernelhive.madekivi.fi/os/hpuxvue) answers with **HP VUE** — two rival visions of what a *1990s* Unix workstation should look like. [Rhapsody](https://kernelhive.madekivi.fi/os/rhapsody) is the missing link between NeXT and Mac OS X, the NeXT system wearing a Mac face. [BeOS](https://kernelhive.madekivi.fi/os/beos) is the fast, doomed upstart of the late nineties. And [Mac OS 7.5.3](https://kernelhive.madekivi.fi/os/macos753) runs on emulated *68040* hardware. [Tru64 UNIX](https://kernelhive.madekivi.fi/os/tru64), which arrived last week, got past the licensing wall that kept it shut, so the museum now stands at 68 machines, 65 of them open to visitors.

### Major features

The museum now has <u>a private 1990s internet with no way out</u>. Sign into **ICQ** on [Windows 98 SE](https://kernelhive.madekivi.fi/os/win98se) and you can message someone at a [Solaris](https://kernelhive.madekivi.fi/os/solaris) workstation — or at [Windows 2000](https://kernelhive.madekivi.fi/os/win2000), [NT 4](https://kernelhive.madekivi.fi/os/nt4), the [Tru64](https://kernelhive.madekivi.fi/os/tru64) *Alpha*, or [BeOS](https://kernelhive.madekivi.fi/os/beos). All six carry each other in their contact lists, and a chatbot named HiveBot says hello about thirty seconds after one wakes up. Open **Internet Explorer 5** on that same Windows 98 and you land on 1998 web pages exactly as they were: real archived captures, nothing later than the end of 2000, so period sites work the way they did then, or break the way they did then. There is a period search engine over them too, with **AltaVista**-styled results and a **Yahoo!**-styled directory. BeOS browses the same pages in **NetPositive**. Nothing on that network can reach today's internet.

### Quality improvements

Machines that used to make you wait mostly don't any more. The [Tru64](https://kernelhive.madekivi.fi/os/tru64) *Alpha* puts its **CDE** desktop on screen in about six seconds instead of a seven-to-ten-minute boot; [Windows 2000 on *Alpha*](https://kernelhive.madekivi.fi/os/w2kalpha) comes back complete in three seconds instead of eighty; [Mac OS 7.5.3](https://kernelhive.madekivi.fi/os/macos753) returns in a third of a second, pixel for pixel where you left it. Typing got honest: [Windows 3.11](https://kernelhive.madekivi.fi/os/win311) no longer freezes after a few dozen keystrokes, the [VIC-20](https://kernelhive.madekivi.fi/os/vic20) stopped quietly swallowing letters, and [NEWS-OS](https://kernelhive.madekivi.fi/os/newsos) no longer scrambles a fast-typed line. Dragging on the Apple machines holds all the way to where you let go, and the Commodore machines stopped clicking through the speakers on every reset. Every machine's write-up is now checked against primary sources and linked to its relatives on the floor.

### Also this week

- Ask twice for a page the archive is missing and the museum goes and mirrors it, so its 1990s web grows from what visitors actually try to visit
- The Unix machines chat in a real window now: **Pidgin** on [Solaris](https://kernelhive.madekivi.fi/os/solaris), **Gaim** on the [Tru64](https://kernelhive.madekivi.fi/os/tru64) *Alpha*, in place of a terminal client
- [BeOS](https://kernelhive.madekivi.fi/os/beos) signs on through an older, pre-OSCAR door than anything else on the network — the only machine here that still speaks it
- The collection opens as a folding index by decade, and the filter above it understands the shorthand people actually type
- [Sony's NEWS portable](https://kernelhive.madekivi.fi/os/newsos) folds a 1120x780 monochrome LCD over its *R3000*: the line was Japan's answer to Sun, sold to its universities
- [Apple's Unix](https://kernelhive.madekivi.fi/os/aux) arrived with **QuickTime**, man pages and a shelf of Unix games — fortune, wump — sitting under the Finder
- **HP VUE** is the desktop **CDE** was built from, so [HP-UX](https://kernelhive.madekivi.fi/os/hpuxvue) now stands beside the CDE machines as their ancestor
- [SunOS](https://kernelhive.madekivi.fi/os/sunos414) is placed deliberately next to the CDE Solaris machine: same vendor, same *SPARC*, the rival desktop that lost
- Photographs of the real hardware sit beside the write-ups now — the BeBox, a Quadra 800, an HP 9000 B180L
- The picture stops dropping to a soft, low-detail mode for no reason: the stream had been reading its own keyframes as a slow connection
- The space bar on the [Sinclair QL](https://kernelhive.madekivi.fi/os/sinclairql) typed nothing at all. It types now, and a burst-typed line keeps its order

*35,569 lines of code.*

## Week 2 · Twenty-two machines in one week · 2026-08-09 09:00 – 2026-08-16 09:00

### New stations

<u>Twenty-two machines joined the floor in a single week</u>, taking the collection to 61 machines, 57 of them open to visitors. Three Xerox machines arrived together: the *1973* [Alto II](https://kernelhive.madekivi.fi/os/alto), where the desktop and the mouse began; the *1981* [Star 8010](https://kernelhive.madekivi.fi/os/star) *"Dandelion"* running **ViewPoint 2.0**; and the *1985* [Xerox 6085](https://kernelhive.madekivi.fi/os/daybreak) *"Daybreak"*. DEC is here as three different PDP-11s now — **2.11BSD** on a [PDP-11/70](https://kernelhive.madekivi.fi/os/pdp11), the oldest lineage in the collection; the *1973* [GT40](https://kernelhive.madekivi.fi/os/gt40), a small one wired to a vector display and a light pen, drawing **Lunar Lander**; and a third [PDP-11](https://kernelhive.madekivi.fi/os/decos) that lets you pick **RT-11**, **RSX-11M** or **RSTS/E** at the prompt. Seven home computers came in one wave, from the [ZX Spectrum](https://kernelhive.madekivi.fi/os/zxspectrum) to the [BBC Micro](https://kernelhive.madekivi.fi/os/bbcmicro) and the *68008* [Sinclair QL](https://kernelhive.madekivi.fi/os/sinclairql), joined by four more Commodores, a *NeXTcube* running [NeXTSTEP 3.3](https://kernelhive.madekivi.fi/os/nextstep), a second [SGI Indy](https://kernelhive.madekivi.fi/os/indyr4400), and the [ARM Evaluation System](https://kernelhive.madekivi.fi/os/armeval) — the first ARM product ever sold. Two *AlphaServer*s closed the week: [Windows 2000 RC2](https://kernelhive.madekivi.fi/os/w2kalpha), the last Windows ever built for *Alpha*, and [Tru64 UNIX 5.1B](https://kernelhive.madekivi.fi/os/tru64).

### Major features

Every machine is now shown as its own screen and nothing else: the emulator's window furniture is out of the picture entirely. The [Alto](https://kernelhive.madekivi.fi/os/alto) is the proof. It stands up, in the tall portrait shape of its own display — 606 by 808 dots, the proportions of a sheet of paper — with no letterbox and nothing painted around it. A few machines never had a pointer that could jump straight to where you touch; their cursor drifts toward it instead, and those now say so before you open one, so period behaviour does not read as a fault. And the [ARM Evaluation System](https://kernelhive.madekivi.fi/os/armeval), which has no operating system to type into, puts its four commands on screen at one tap each.

### Quality improvements

Machines used to boot when you opened them. Now they are simply left running, held at the moment they were last used, and wake in well under a second — no boot sequence you did not ask to watch. [Windows 2000 on the *Alpha*](https://kernelhive.madekivi.fi/os/w2kalpha) picks up exactly where it stopped, its own clock included, and answers in ten seconds where it used to take twenty-five. Pointing at [NeXTSTEP](https://kernelhive.madekivi.fi/os/nextstep) finally works the way you expect: the cursor lands where you put it. And typing got honest — hammer a line into the [KC 85/4](https://kernelhive.madekivi.fi/os/kc854) or the [Micro-Professor](https://kernelhive.madekivi.fi/os/mpf2) and every letter arrives, in order, so "HELLO" no longer turns up as "HLLO".

### Also this week

- The [PET 2001](https://kernelhive.madekivi.fi/os/pet2001) of *1977*: screen, keyboard and cassette deck welded into one sheet-metal trapezoid you could carry home and switch on
- The [CBM 8032](https://kernelhive.madekivi.fi/os/cbm8032) is Commodore's office machine — 80 columns of green text, and no colour, no sprites and no sound chip at all
- The [C128](https://kernelhive.madekivi.fi/os/c128) is three computers in one case, and the only machine here that can show you **CP/M**, the office system MS-DOS replaced
- The [CBM 610](https://kernelhive.madekivi.fi/os/cbm2) says 128 on the screen and is not a C128: Commodore's *1982* try at a business computer, cancelled almost immediately
- The [ZX81](https://kernelhive.madekivi.fi/os/zx81): £69.95 in kit form, one kilobyte of memory, no sound and no colour — and a million and a half of them sold
- The [Oric Atmos](https://kernelhive.madekivi.fi/os/oricatmos) has a BASIC in which ZAP, PING, SHOOT and EXPLODE each make the noise they are named after
- The Welsh-built [Dragon 32](https://kernelhive.madekivi.fi/os/dragon32) runs a *Motorola 6809*, the best *8-bit* processor anyone shipped, and cannot draw a lower-case letter
- The [KC 85/4](https://kernelhive.madekivi.fi/os/kc854) was East Germany's school computer, and it prints its own list of commands at power-on so a beginner has somewhere to start
- Each of the [ZX Spectrum](https://kernelhive.madekivi.fi/os/zxspectrum)'s forty rubber keys carries a whole BASIC word: press P and PRINT appears
- The [Sinclair QL](https://kernelhive.madekivi.fi/os/sinclairql) shipped with firmware that did not fit — the earliest buyers got the missing part on a cartridge hanging out of the back
- The [BBC Micro](https://kernelhive.madekivi.fi/os/bbcmicro)'s BASIC has a *6502* assembler inside it, and the team who finished the machine went on to design the *ARM*
- Reaching the [Star](https://kernelhive.madekivi.fi/os/star)'s desktop once meant a 22-minute cold boot and six keystrokes; it is now sitting there waiting when you arrive
- Every window on the [6085](https://kernelhive.madekivi.fi/os/daybreak) has a named tab instead of a title bar, and a line of prose along the top narrates what the system is doing
- The [GT40](https://kernelhive.madekivi.fi/os/gt40) has no pixels at all — an electron beam draws each line exactly where the program says, and nothing in between
- The two [SGI Indys](https://kernelhive.madekivi.fi/os/indyr4400) sit side by side on purpose: same blue case, same **IRIX 6.5**, a different *MIPS* chip inside each
- [Tru64](https://kernelhive.madekivi.fi/os/tru64) was born *OSF/1* in 1992 and ended with 5.1B in 2003, when HP retired it and *Alpha* together
- Three operating systems on one [PDP-11](https://kernelhive.madekivi.fi/os/decos), because in 1975 you bought a computer and then chose one to run on it
- Log into the [PDP-11/70](https://kernelhive.madekivi.fi/os/pdp11) as root — there is no password — and the whole operating system's source code is sitting in /usr/src

## Week 1 · The museum opens its source · 2026-08-07 14:37 – 2026-08-09 09:00

### New stations

Two Commodores joined the gallery, both picked after a survey of the *8-bit* and *16-bit* home-computer field. The [VIC-20](https://kernelhive.madekivi.fi/os/vic20) came first, and there is charmingly little to it: open the page and you are looking at the same friendly BASIC screen a child saw on a shop shelf, cursor blinking, ready for you to type. The [Plus/4](https://kernelhive.madekivi.fi/os/plus4) followed, the odder of the pair — Commodore built an office suite into the machine itself, so **3-PLUS-1** (a word processor, a spreadsheet and a card-file program) is there the instant it powers on, with one-tap buttons on the on-screen keyboard to reach each one. On its first day the Plus/4 opened mid-spreadsheet, which rather gave the game away; it now starts where the real machine starts, on the power-on screen that says "3-PLUS-1 ON KEY F1".

### Major features

On 7 August the <u>museum's source code went public</u>. Everything behind the gallery — the site you click through, the software that streams each machine to your browser, and the recipes that build the machines themselves — is now open for anyone to read, learn from, or run themselves, under the MIT licence, with the streaming code under GPL-2.0-or-later. The changes the museum makes to **MAME** and **QEMU** to keep old machines happy are published as public branches too, rather than hidden. A source link now sits in the gallery footer and on the sign-in page, so you can go from a running machine to the code that runs it in one click. Each machine's page also grew a carousel of photographs of the real hardware: over a hundred freely-licensed pictures, every one credited to its photographer. Then someone opened each picture at full size and read its caption — a "tower-case system" turned out to be plainly a laptop. Every caption is now written from the photograph you are actually looking at, and portrait pictures no longer arrive lying on their side.

### Quality improvements

A visitor's typed-in program came back scrambled on the VIC-20, which turned out to be the museum typing faster than the machine could listen. Demonstrations now type at a pace each machine can keep up with, measured against that machine rather than guessed — a fix that also caught the [Amstrad CPC](https://kernelhive.madekivi.fi/os/amstradcpc) quietly rushing since the day it opened. And [IRIX](https://kernelhive.madekivi.fi/os/irix) now opens on a working desktop, icons and toolchest and all, instead of a login screen.

### Also this week

- The VIC-20 still greets a visitor the way it greeted a shopper: CBM BASIC V2, and 3583 BYTES FREE — every byte an unexpanded machine had
- The *Commodore* key exists on no modern keyboard and on no phone at all, so the Plus/4's on-screen keyboard carries a labelled one of its own
- Neither Commodore needs a cartridge or a disk: the emulator already carries their ROMs, the whole of **3-PLUS-1** included
- IRIX types its own login one keystroke per tick — any faster and the machine panics before it ever reaches the desktop
- The photographs on the [Windows NT 3.51](https://kernelhive.madekivi.fi/os/nt351) page are *DEC AlphaStations*: NT ran on far more than beige *x86* boxes
- [9front](https://kernelhive.madekivi.fi/os/ninefront)'s page shows the Bell Labs it descends from — the *DMD 5620* terminal, Thompson and Ritchie, and Glenda, licensed by her creator
- Period advertising is linked, never copied: an *AlphaServer* brochure and a television advert for [OS/2 Warp](https://kernelhive.madekivi.fi/os/os2warp)
- One picture on the [Windows 95](https://kernelhive.madekivi.fi/os/win95) page showed a *386/16*, a machine below the floor **Windows 95** itself demands; it was replaced
- Every gallery image is cleared against Wikimedia's own licence record by a script, which caught two invented file titles on its first run
- A survey of the *PDP-11* family and of thirty more home computers went into the notes before any of them got a page

*4,967 lines of code.*

## Week 0 · The month the museum was built · 2026-07-07 21:39 – 2026-08-07 14:37

### The story so far

Kernel Hive is a home lab that behaves like a museum. Inside one computer sit dozens of old, obscure and occasionally alarming operating systems, and they are not screenshots, and not an emulator you download and configure: they are <u>real machines, switched on right now</u>, their screens streamed into your browser tab, with a pointer and a keyboard that actually work. You download nothing and install nothing: you pick a machine off the wall and it is simply there, waiting where the last visitor left it. It began on 7 July 2026 with a private project, a single box under a desk, and twenty-four of these systems already running on it at once. The month that followed is the museum being built — machine after machine coaxed first into running unattended, then into being usable by a stranger who has never seen it before. It closes on 7 August 2026, the day the whole thing was published for anyone to read.

### New stations

By the end of the month thirty-seven machines were open to visitors, plus [macOS](https://kernelhive.madekivi.fi/os/macos) and [RISC OS](https://kernelhive.madekivi.fi/os/riscos) as posters — illustrated wall placards standing in for machines not yet running. The workstations came first, the expensive kind nobody had at home: [Windows NT 3.51](https://kernelhive.madekivi.fi/os/nt351) and [NT 4.0](https://kernelhive.madekivi.fi/os/nt4) on full-size desktops, [OS/2 Warp](https://kernelhive.madekivi.fi/os/os2warp) at high resolution through IBM's own **GENGRADD** driver, [Solaris](https://kernelhive.madekivi.fi/os/solaris), and [OpenVMS](https://kernelhive.madekivi.fi/os/openvms) 9.2, a *2024* release still presenting the **DECwindows** Motif desktop. Microsoft's whole arc is here too, from [MS-DOS with Windows 1.01](https://kernelhive.madekivi.fi/os/msdoswin1) to a [Windows 11](https://kernelhive.madekivi.fi/os/win11) that installed itself without a single click, by way of [Windows 95](https://kernelhive.madekivi.fi/os/win95). Then the home computers: the *8-bit* [Commodore 64](https://kernelhive.madekivi.fi/os/c64), [Apple II](https://kernelhive.madekivi.fi/os/apple2) and [Amstrad CPC](https://kernelhive.madekivi.fi/os/amstradcpc), followed by the *68000* generation, [Amiga](https://kernelhive.madekivi.fi/os/amiga) and [Atari ST](https://kernelhive.madekivi.fi/os/atarist). The oddities earn their place: [Red Star OS 2](https://kernelhive.madekivi.fi/os/redstar2) and [Red Star OS 3](https://kernelhive.madekivi.fi/os/redstar3), North Korea's own desktop, kept strictly air-gapped; [TempleOS](https://kernelhive.madekivi.fi/os/templeos); and a [Multitech Microprofessor II](https://kernelhive.madekivi.fi/os/mpf2) from *1982* that has a keyboard and nothing else. Weeks then disappeared into [SGI IRIX](https://kernelhive.madekivi.fi/os/irix) on a *1993 Indy*, the machine that taught this project most of what it knows.

### Major features

What you can do with them is the whole point. Move your mouse and the pointer moves; type and the letters land; drag a window, open a menu, go looking for whatever the makers left inside. None of these systems was built with a visitor in mind, so each needed its own arrangement. [Windows 95](https://kernelhive.madekivi.fi/os/win95), [TempleOS](https://kernelhive.madekivi.fi/os/templeos) and [OS/2 Warp](https://kernelhive.madekivi.fi/os/os2warp) each needed a small program installed inside them, listening for where you point, before the cursor would go there; [Solaris](https://kernelhive.madekivi.fi/os/solaris) could not take a pointer at all, and now it takes one. Type on a Finnish layout and the machine still receives what you meant, and on a phone an on-screen keyboard appears. You can watch a machine boot from cold, with sound, or skip the wait: [SGI IRIX](https://kernelhive.madekivi.fi/os/irix) wakes where it was left in five seconds, against six and a half minutes from cold. Every machine has an exhibit poster too — a written placard on what it was and why it mattered — and behind the **3D Museum** link the whole collection stands in one hall, sectioned by decade, that you can walk through.

### Quality improvements

Most of the month went into making this feel less like a remote control and more like sitting at the machine. The delay between moving your hand and the screen answering was cut hard. The picture now adapts to your connection instead of stalling on it, and joining a busy machine shows you its desktop straight away instead of grey. Typing is paced to each machine, after an *8-bit* computer quietly swallowed half a typed line. On a phone the whole vocabulary of a mouse had to be rebuilt out of fingers: tap, hold to drag, pinch to zoom, a badge to arm a right-click. And where an emulator itself was wrong, it was fixed and the fix published — including a mouse bug that could leave [SGI IRIX](https://kernelhive.madekivi.fi/os/irix) ignoring the pointer completely.

### Also this week

- Microsoft's middle years fill a shelf of their own: [Windows 3.11](https://kernelhive.madekivi.fi/os/win311), [Windows 98 SE](https://kernelhive.madekivi.fi/os/win98se), [Windows 2000](https://kernelhive.madekivi.fi/os/win2000) and [Windows XP](https://kernelhive.madekivi.fi/os/winxp)
- [Windows NT 3.51](https://kernelhive.madekivi.fi/os/nt351) still runs **Program Manager**; [NT 4.0](https://kernelhive.madekivi.fi/os/nt4) beside it wears the Windows 95 shell on the same kernel
- [Windows 95](https://kernelhive.madekivi.fi/os/win95) has **Duke Nukem 3D** and **GTA** installed and launching; Windows 98 SE still has **Space Cadet** pinball
- Three pocket Linuxes joined the wall: [Android](https://kernelhive.madekivi.fi/os/android), Jolla's [Sailfish OS](https://kernelhive.madekivi.fi/os/sailfishos), and [postmarketOS](https://kernelhive.madekivi.fi/os/postmarketos) of *PinePhone* mainline fame
- [SerenityOS](https://kernelhive.madekivi.fi/os/serenityos) is a love letter to the late-*90s* desktop, written from scratch on camera, live on YouTube
- [ToaruOS](https://kernelhive.madekivi.fi/os/toaruos) is one developer's UNIX with a real windowing compositor; [HelenOS](https://kernelhive.madekivi.fi/os/helenos) builds a whole desktop on message passing
- [KolibriOS](https://kernelhive.madekivi.fi/os/kolibrios) is a complete graphical operating system written in pure assembly that fits on one floppy disk
- [Tiny Core Linux](https://kernelhive.madekivi.fi/os/tinycore) is graphical Linux in about *16 MB*, with the whole system living in RAM
- [ReactOS](https://kernelhive.madekivi.fi/os/reactos) is an open-source Windows 2000, reimplemented from scratch to run the same binaries
- [Haiku](https://kernelhive.madekivi.fi/os/haiku) carries BeOS forward, yellow window tabs and all, and [AROS](https://kernelhive.madekivi.fi/os/aros) brings back the Amiga **Workbench** with none of the original code
- [9front](https://kernelhive.madekivi.fi/os/ninefront) keeps Bell Labs' successor to Unix alive, where everything is a file and the file can be on another machine
- [QNX Neutrino](https://kernelhive.madekivi.fi/os/qnx) is a hard-real-time microkernel whose **Photon** microGUI once held a whole desktop and a web browser
- [Alpine](https://kernelhive.madekivi.fi/os/alpine) quietly runs half the containers on Earth; [FreeDOS](https://kernelhive.madekivi.fi/os/freedos) keeps a C prompt that never died
- [Commodore 64](https://kernelhive.madekivi.fi/os/c64) and [Apple II](https://kernelhive.madekivi.fi/os/apple2) both run **GEOS** — a windows-icons-menus desktop on a *1 MHz* machine
- [Amiga 500](https://kernelhive.madekivi.fi/os/amiga) arrives on **Workbench 1.3**, with the custom chips: *blitter*, *copper* and four-channel *Paula* sound
- [Atari ST](https://kernelhive.madekivi.fi/os/atarist) boots **EmuTOS** into the *GEM* desktop, built-in *MIDI* ports and all
- The [Microprofessor II](https://kernelhive.madekivi.fi/os/mpf2) has no software to load at all, so it comes with a program you type in yourself
- [Windows 11](https://kernelhive.madekivi.fi/os/win11) began as a poster on the wall and was promoted to a machine you can sit down at
- [Red Star OS 3](https://kernelhive.madekivi.fi/os/redstar3) reaches a logged-in desktop with no input at all: **KDE** on Fedora, reshaped in the DPRK to look like a Mac
- The recorded cold boot of [SGI IRIX](https://kernelhive.madekivi.fi/os/irix) carries the *Indy*'s PROM startup chime, captured along with the picture
