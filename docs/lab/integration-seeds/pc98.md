## Emulator acquisition

Pin NP2kai source:
- https://github.com/piepacker/np2kai

Build the SDL/X11 frontend that works without a desktop environment. Stage the binary and required shared libs in the station container/root.

NP2kai BIOS assets commonly include:
- `bios.rom`
- `font.rom` or supported font substitute
- `itf.rom`
- `sound.rom`
- optionally `bios9821.rom` / `d8000.rom`
- YM2608 rhythm samples if sound is enabled

For first smoke, sound is optional.

## OS media acquisition

Use Japanese PC-98 media:
- MS-DOS 6.2 for PC-98
- Windows 3.1 NEC PC-9801 build

Preservation indexes:
- https://www.winworldpc.net/product/windows-3
- https://www.pc98.org/

Stage original floppy/hard-disk images as fetched; convert only inside the builder if NP2kai requires a different container format.

## First smoke procedure

Run NP2kai once interactively under the station Xvfb:

```bash
export DISPLAY=:<display>
./np2kai
```

Configure:
- 386/486-class PC-98 profile
- enough RAM for Windows 3.1
- hard disk image
- first DOS install floppy

Install MS-DOS, then Windows 3.1.

After a working configuration exists, commit a generated station-local `np2kai.cfg` fixture instead of relying on hand-set GUI preferences.

## Windows 3.1 display target

NP2kai supports WAB (Window Accelerator Board) emulation.

Recommended museum target:
- WAB enabled
- WAB type: PC-9821Xe10/Xa7e/Xb10 built-in
- Windows 3.1 display: **640×480, 256 colors**

NP2kai documents the Windows setup choice:
- `640x480 256色 16ドット(9821シリーズ対応)`
- or 12-dot font variant

If the stock Windows driver renders badly, the documented replacement is `EGCN4.DRV` + `PEGCV8.DRV` extracted from a Japanese Windows 98 `MINI3.CAB`.

Do not enable WAB until plain DOS/Windows VGA-equivalent output is proven.

## Input strategy

XTEST into the NP2kai window is the first path:
- absolute host pointer if NP2kai maps it sanely
- keyboard through X11
- Japanese IME/input only if the guest scene needs text entry

A visitor should be able to operate Program Manager/File Manager without knowing Japanese.

## Intended golden scene

Japanese Windows 3.1 Program Manager with:
- Japanese group names/text visible
- one representative Japanese application/icon visible
- DOS prompt reachable but not foregrounded
