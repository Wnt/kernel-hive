# Windows NT 3.51 gallery station

**Status: LIVE.** Station `nt351` (VMID 83, UDP/54083) runs Windows NT
Workstation 3.51 at a curated 1024x768x65,536-color (16bpp) Program Manager
scene. Reset is an internal `loadvm golden`; the display, pointer, mouse
buttons, drag, and keyboard are verified through real framebuffers.

## Device-set contract

The checkpoint VM state records the exact guest-visible QEMU topology:

```text
/opt/qemu-cirrusfix/bin/qemu-system-i386 -L /usr/share/kvm
-name streamhost-nt351
-accel tcg -m 64 -smp 1
-machine isapc -cpu 486
-rtc base=localtime
-cdrom /data/gallery-guests/Nt351/NTWKS351_UPD.iso -boot order=c,menu=off
-device isa-cirrus-vga,global-vmstate=on
-display dbus,p2p=on,audiodev=snd0
-audiodev dbus,id=snd0,out.frequency=48000,out.channels=2,out.format=s16
-device sb16,audiodev=snd0
-drive file=$D/nt351-golden.qcow2,format=qcow2,if=ide
-net nic,model=ne2k_isa -net user
-loadvm golden
-qmp unix:$D/qmp.sock,server=on,wait=off
-pidfile $D/qemu.pid
```

`isapc` is load-bearing: the PCI VGA device fails because the machine has no
PCI bus, while modern PCI machines do not provide the compatible NT 3.51
environment. `isapc` has no KVM path, so the station intentionally uses TCG.
Capture-time VNC and silent audio may replace the production dbus backends; all
guest-visible devices must remain identical.

The executable path is also load-bearing. The dedicated build carries
`streamhost/qemu-patches/0004-cirrus-blt-rop1-fill.patch`, which makes
source-independent Cirrus ROP1 fills execute instead of incorrectly returning
as no-ops. The stock QEMU corrupts NT 3.51 accelerated scroll and window
redraws, so this station must not be launched with the system QEMU.

The disk is **480 MiB FAT16**, not 1 GiB. A 1 GiB installation completed and
reached Program Manager during Setup, but a subsequent cold start hung at
`Booting from Hard Disk...`: the legacy `isapc` BIOS exposes 16-head CHS
geometry and the volume crosses its old 504 MiB boundary. The 480 MiB disk
cold-boots repeatedly and is the production image.

## Installed scene

Setup selected:

- Windows NT Workstation, per-server licensing
- NE2000 ISA at I/O `0x300`, IRQ `9`
- TCP/IP with DHCP, workgroup `WORKGROUP`
- Cirrus Logic display hardware at `1024x768`, 65,536 colors (16bpp)
- no printer and no screensaver

The accelerated Cirrus miniport is enabled with:

```text
HKLM\SYSTEM\CurrentControlSet\Services\cirrus
  Start = 1
HKLM\SYSTEM\CurrentControlSet\Services\cirrus\Device0
  DefaultSettings.BitsPerPel = 16
  DefaultSettings.XResolution = 1024
  DefaultSettings.YResolution = 768
  DefaultSettings.VRefresh = 45
  DefaultSettings.Interlaced = 1
```

`ForceVga` is absent from `cirrus\Device0`; the `VgaStart` and `VgaSave`
fallback mode overrides are also absent. The transition required one boot with
`ForceVga=1`, after which it was removed from the running guest before capturing
the internal checkpoint. The supported production path is therefore
`-loadvm golden`, not a cold boot of the transition state.

The 2026-07-27 standard-VGA fallback was a temporary workaround. Raw QMP
frames had proved that stock QEMU dropped accelerated redraws: Write retained
old pages after ten Page Downs, and window/icon drags left stale fragments.
With the ROP1-fill patch, three full adversarial runs are clean at
1024x768x16bpp. Program Manager and its Main group are maximized.

The Main group is focused, screensaver is `(None)`, cursor blink and Mouse
Tracking Speed are set to their slowest positions, and the pointer is parked at
the lower-right edge. Two idle frames are byte-identical.

## Pointer calibration

NT 3.51 on `isapc` exposes only its PS/2 relative mouse; a QEMU vmmouse/tablet
is unavailable. QEMU's `Mouse.SetAbsPosition` is a no-op on this device set, so
the browser still sends absolute display coordinates while the daemon's
`dbus-rel` bridge edge-homes and emits bounded `Mouse.RelMotion` deltas. The
checkpoint sets Mouse Tracking Speed to its slowest position, removing the
speed-dependent overrun seen at the default setting. The measured live
calibration is:

```text
--pointer abs --input-backend dbus-rel
--cursor-scale 1.0 --cursor-off-x 0 --cursor-off-y 0
```

This was derived with a real live client and framebuffer cursor locations,
then reverified at the title-bar and icon targets used by the live adversarial
proof.
Clicks, a Program Manager window drag, and Ctrl+Esc keyboard make/break were
also framebuffer-verified. Recalibrate if the resolution or Windows mouse
control-panel settings change.

## Patched-QEMU maintenance

`nt351` pins `/opt/qemu-cirrusfix/bin/qemu-system-i386 -L /usr/share/kvm`.
That binary must contain
`streamhost/qemu-patches/0004-cirrus-blt-rop1-fill.patch`. Whenever the
packaged QEMU version changes, rebuild and reverify the dedicated binary before
updating this station. Never replace or patch the system QEMU for this fixture.
