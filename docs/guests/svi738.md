# Spectravideo SVI-738 CP/M

Implementation awaiting browser acceptance, 2026-10-03. Slot/VMID 224, UDP 54224.
Offline, keyboard-only, host-native MAME 0.289 (`svi738sw`).
No deployment or production browser proof is claimed by this document.

## Fixture

Stock Finland/Sweden SVI-738 hardware: Z80 at 3.58 MHz, 64 KiB RAM,
16 KiB VRAM, PAL V9938, AY-3-8910, one single-sided 3½-inch floppy.
The V9938 does not make the stock computer MSX2. CP/M provides its own
International keyboard tables: this station does **not** claim Finnish CP/M.

Cold boot reaches `SPECTRAVIDEO CP/M-80 Revision 2.28`, X'PRESS release 2.1,
International keyboard, `A>`. The system belongs to the CP/M 2.2 family.
`STAT CON:=UC1:` selects 80 columns; `STAT CON:=CRT:` returns to 40.
`MBASIC` starts BASIC-80 5.21. `RUN "HELLO"` loads the supplied program;
`SYSTEM` returns to CP/M. The Type demo action enters a new BASIC program.
The final RUN is deliberately left for the visitor to execute with Enter.

ED, ASM, LOAD, DDT, PIP and system utilities remain available. Archive-owner
applications and personal files were removed from the directory and replaced
with museum-authored HELLO.BAS/WELCOME.TXT. WordStar and alternate MSX-DOS
boots are not advertised as available.

## Reproduction and provenance

Run `scripts/build-guests/tiles/svi738.sh` on the host (requires libdsk-utils),
then `scripts/build-guests/emulators/build-mame-native.sh svi738`.
The fleet pin is `mame0289`, f34f02505e32c1993c6a782b6814232cbfc74e36.

sibling to reuse this binary. The measured build reused the existing MSX2
source/object tree through a reflink copy and enabled shared ccache: 24
cacheable compilations, 5 hits, 19 misses; unchanged objects did not recompile.

## Runtime and proof

Shared `stations/mame-native/x11-runtime.sh` supplies drawshm, mamesock and
SDL-disk/FIFO audio. A physical-key map was generated from this driver.
40/40 ms minimum pacing and `MAME_CTL_KEY_EXCL=:KEY` protect its scanned matrix.
Screen-only view removes MAME's Caps/Drive artwork from the guest image.
No MACHINE_SUPPORTS_SAVE flag: cold relaunch is the initial reset mechanism.
MAME_NATIVE_DISK_TEMPLATE makes a writable session copy of the immutable disk.

Sandbox framebuffer evidence: original and composed disks boot; DIR lists the
curated files; STAT reports 202 KiB free; MBASIC reaches its banner and Ok.
The complete demo typed via physical KEY press/release through the generated
map prints its greeting and squares 1–64, then returns Ok.
MBASIC's first load took 14.85 seconds wall time in the measured loaded host;
the demo must allow disk loading after its first command. A short framebuffer
settle can mistake the quiet floppy interval for completion.

Darklaunch rig: `/data/vms/sandbox/svi738/smoke`, UDP 54224, production daemon
mamesock/keymap/audio path. The coordinator owns final browser and reset checks.
Disposable original proof rig is separate; never reset a live station to test.
