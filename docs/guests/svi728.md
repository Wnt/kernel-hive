# Spectravideo SVI-728

Implementation awaiting browser acceptance, 2026-10-03. Slot/VMID 223, UDP 54223.
International SVI-728 (1984): MSX1, Z80 3.58 MHz, 64 KiB RAM, 16 KiB VRAM,
PAL TMS9929A video, AY-3-8910 sound. No disk expansion or network is fitted.
The visitor's 728 is represented directly; this is not the Philips MSX2 station.

## Fixture and controls

MAME 0.289 `svi728` boots MSX BASIC 1.0, 28815 bytes free, `Ok`.
The Type demo button enters a graphics/text/music program. Press Enter after
RUN to execute it. Editing a line number replaces that program line.
Reset cold-boots to an empty BASIC prompt, discarding the visitor's program.

Host-native drawshm at 1024×768, mamesock physical keys, FIFO audio,
keyboard-only interaction. The keymap comes from this driver's KEYDUMP.
Pacing uses 150/100 ms hold/gap with MAME_CTL_KEY_EXCL=:KEY after dropped
characters were observed under heavy host load. Browser pacing is a release gate.
Screen-only view excludes emulator artwork. No savestate is relied upon.

## Build and provenance

`scripts/build-guests/tiles/svi728.sh` fetches and verifies the BIOS.
`scripts/build-guests/emulators/build-mame-native.sh svi728` builds it with the
fleet mame0289 pin (f34f02505e32c1993c6a782b6814232cbfc74e36).
The initial implementation reuses the combined 728/738 binary built in the
738 sandbox: identical emulator pin and integration patches, both drivers
included. Shared ccache was enabled; the existing MSX2 object tree was reused.

ROM source: https://archive.org/download/mame-0.264-roms-non-merged/MAME%200.264%20ROMs%20%28non-merged%29/svi728.zip
