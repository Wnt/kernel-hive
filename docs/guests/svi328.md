# Spectravideo SV-328 BASIC

Host-native offline exhibit, implemented and sandbox-proven on 2026-10-03.
ID `svi328`, slot/VMID label 221, UDP 54221; keyboard only.

MAME 0.289 (`mame0289`, f34f02505e32c1993c6a782b6814232cbfc74e36)
uses `svi328` in `src/mame/svi/svi318.cpp`: PAL TMS9929A, Z80A,
64 KiB main RAM and 16 KiB video RAM. No disk, cartridge or expansion card
is attached. The v111 BIOS boots to **SV extended BASIC version 1.1**,
**Copyright 1983 (C) by Microsoft corp.**, and `Ok` on a blue display.

## Reproduce

Run `scripts/build-guests/tiles/svi328.sh` to acquire the individual BIOS
archive and extract its members. Then run
`scripts/build-guests/emulators/build-mame-native.sh svi328` with an isolated
work directory and output. Compiler caching must be enabled (`MAME_CCACHE=1`);
verify that generated makefiles contain `ccache gcc` and `ccache g++`.
The 2026-10-03 native build reused existing core objects and compiled 43
cacheable units: 5 cache hits and 38 misses. The final rebuild hit all 7
cacheable compiles and passed both framebuffer gates. Both exhibits use the
same narrow binary, copied to separate assets directories.

Runtime uses the shared MAME launcher, drawshm at 1024×768, mamesock matrix
keys and SDL audio into the daemon FIFO. Keymap was generated from the
running machine's KEYDUMP: 93 fields, 85 mapped wire keys. Unmapped fields
are unused rows, Select, Print and keypad comma. STOP is host End;
Ctrl+End interrupts a program. Colon and semicolon use the opposite Shift
levels from a US PC, so `keyboard.charMap` swaps them. Other demo punctuation
(quotes, comma, asterisk) is native. Pacing is 100 ms hold / 100 ms gap,
with `MAME_CTL_KEY_EXCL=:KEY`; Type uses 500 ms per character.

The visitor's own keys and the on-screen keyboard use the charMap too
(`keyboard.physical`, 2026-10-05). Checked on the frame with every printable
ASCII character typed through the SPA's real key path on a rig of this
station's binary: each arrives as itself except `` ` `` and `|`, which the SV-328
has no key for (`typeIn.unreachable`; the US `` ` `` key is not wired and `|`
gives `~`). The machine's `\ ~` key puts `~` on Shift+`\`, so the map now
sends `~` there; it had been listed unreachable. The SV-328's Caps Lock is its
own, so a visitor's Caps Lock inverts letter case (docs/TYPE-IN-EDITOR.md).
Evidence: `/data/vms/streamhost/stations/svi328/evidence/physical-charmap-2026-10-05/`.
**Live since 2026-10-05**: the editor typed the Celsius example and LIST was exact;
the visitor's `PRINT "!#$%&'()*+,-./:;<=>?@[\]^_{}~";1+2*3` printed every symbol
and 7; `PRINT "Hello World"` kept its case.

## Demo and reset proof

The original Type program clears BASIC memory, enters CLS, a title and a
FOR/NEXT loop, then offers RUN. A framebuffer captured through the matrix
path shows **SPECTRAVIDEO SV-328** and the five rows **1 1**, **2 4**,
**3 9**, **4 16**, **5 25**, followed by `Ok`. Visitors can LIST, edit a
numbered line and RUN again. The SPA leaves the final RUN for visitor Enter.

Reset is cold relaunch (`MAME_NATIVE_CHECKPOINT=0`), which clears program RAM
and sound. No MAME state is shipped. The coordinator ran the actual web Type action in staged VNC Chrome: all
numbered lines appeared correctly, and visitor Enter printed the title and
five square values. Production POST /restore/svi328 returned HTTP 200 and the browser showed
the clean startup banner and empty prompt. Browser BEEP reached WebAudio
with nonzero PCM (peak 0.9043). Published at a50b5e0d with its notes, actual
framebuffer hero and both licensed hardware images, all loaded in Chrome. The sandbox proof rig includes the
production daemon, matrix keymap and FIFO audio path.

## Shifted characters: the modifier lead (2026-10-04)

`SH_KEY_MOD_LEAD_MS=10` in the station fixture: the `ctlsock` module holds a
key press until the Shift edge in front of it has been in the matrix for 10
emulated ms, so the BIOS's matrix scan sees SHIFT before the key it modifies.
This machine lost no shifted character on the old engine. It gets the fleet's
10 ms anyway, five times the largest threshold measured on a MAME machine
([`../TYPE-IN-EDITOR.md`](../TYPE-IN-EDITOR.md#shifted-characters-the-modifier-lead)).
`typeIn.perCharMs` 500 already covers it: HOLD 100 + max(GAP 100, LEAD) + LEAD
= 210.

**Rig proof (2026-10-04).** A rig of this station's own binary and cold boot
took the keys through a sandbox daemon, exactly as the editor sends them
(`typeListing()` replayed by `key-burst-proof.mjs --edges`). The rig ran at
1.00x real time. A 16-line listing with `"A+B*C:D(E)$!";1+2*3` on every line
(`code-upper`, so the keywords go down as Shift+letter too), LISTed
pixel-identical to a slow reference typed with Shift 60 ms ahead, in 2 of 2
runs, and all three examples typed exactly, twice each. The cold-boot screen
is pixel-identical under the new binary, and the savestate signature is
unchanged (`77fc8a41`, 950 entries).

**Live since 2026-10-04.** The real editor typed *Celsius to Fahrenheit*; LIST
was exact, RUN answered 100 with `100 C IS 212 F` and `WATER BOILS.`, and
Restore to golden brought back the BASIC banner. Rollback:
`assets/svi328/mame-native/svi328.pre-shiftlead-20261004` and
`station.env.pre-shiftlead-20261004`. Evidence:
`/data/vms/streamhost/stations/svi328/evidence/shift-lead-2026-10-04/`.
